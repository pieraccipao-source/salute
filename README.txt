SALUTE Fitness & Nutrition

Diario personale per allenamento, alimentazione, composizione corporea e foto dei progressi.

GitHub Pages
Carica i file nella radice del repository. In Settings → Pages seleziona
Deploy from a branch, scegli il ramo principale e la cartella /(root).
Apri l’indirizzo HTTPS che GitHub Pages indica a pubblicazione conclusa.

iPhone
Apri il sito in Safari, tocca Condividi e scegli Aggiungi alla schermata Home.
L’app conserva i dati nel browser del dispositivo. Usa Archivio per il backup
e per trasferire i dati tra dispositivi o indirizzi del sito. Il backup contiene
anche le fotografie e va conservato in un luogo privato.
